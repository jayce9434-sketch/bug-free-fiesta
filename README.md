# UNDERLEAF: Night Shift

A flat-file, offline-capable GitHub Pages bug mission roguelite.

## Core loop
Choose one of six specialists, select one of three procedural contracts, complete a short field mission, earn Sap / Amber / XP, improve the Field Lab, unlock new specialists, and earn deterministic Pattern Chips through feats.

This project intentionally does **not** use breeding, egg hatching, island collection, wave survival, or a simple fight-to-level zone treadmill.

## Controls
Desktop:
- Move: WASD or Arrow Keys
- Specialist ability: Space
- Burst: Shift

Mobile / iPad:
- Left virtual joystick: move
- Large right button: specialist ability
- Small right button: Burst

## Systems
- 6 specialists with materially different abilities
- 6 unlockable sectors
- 5 procedural contract types: Scavenge, Relay, Rescue, Sabotage, Survey
- Visible/fair collision radii
- Permanent Field Lab upgrades
- Common, Uncommon, Rare, Epic, Legendary, Mythical, Divine Pattern Chips earned from feats
- Daily fixed cache, with no wheel or gacha dependency
- Local autosave
- Save export/import/reset
- Exact ADD / SET Test Vault controls for Sap, Amber, and XP
- Separate Master / Music / SFX controls from 0% to 20,000%
- Original vector/canvas visuals and synthesized Web Audio; no CDNs or copied assets
- PWA manifest, app icons, service worker, offline support
- Responsive iPad/mobile and desktop layout
